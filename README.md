# Calculator Project

A simple interactive C++ calculator.

## Features

- Addition, subtraction, multiplication and division
- Modulus (%) and power (^)
- Stores the last 10 calculations
- Shows calculation history
- Handles invalid input
- Prevents division by zero

## How to Run

Compile the program using a C++ compiler and run the generated executable.

## Usage

Enter numbers and an operator when prompted.

- Enter `h` to view the last 10 calculations.
- Enter `q` to quit the calculator.
